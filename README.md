# KKACHI · Homebrew

한국어 업무를 위한 로컬 중심 AI 문서 작업공간의 공식 Homebrew 배포 저장소입니다.

**현재 상태: 첫 서명·공증된 설치 파일 준비 중. Cask는 아직 등록되지 않았으며 설치 명령은 아직 사용할 수 없습니다.**

## 배포 후 설치

```bash
brew install --cask djfksjd/kkachi/kkachi
brew upgrade --cask djfksjd/kkachi/kkachi
```

Apple Silicon과 Intel에 맞는 DMG를 선택하고 버전별 SHA-256을 검증합니다. 서명·공증·출력 검증과 전체 릴리스 파일 검사를 통과한 패키지만 Cask로 등록합니다. macOS 보안 기능을 해제하거나 격리 속성을 제거하지 않습니다.

앱을 지워도 사용자 문서와 작업공간 데이터를 자동 삭제하지 않습니다.
