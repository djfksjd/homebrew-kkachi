# KKACHI · Homebrew

한국어 업무를 위한 로컬 중심 문서 작업공간의 공식 Homebrew 배포 저장소입니다.

**현재 버전: 0.1.0-beta.1 · macOS Apple Silicon·Intel 베타.** Apple Developer ID 서명·공증이 없으며 첫 실행 때 macOS 보안 확인이 필요할 수 있습니다.

## 설치

```bash
brew install --cask djfksjd/kkachi/kkachi
brew upgrade --cask djfksjd/kkachi/kkachi
```

Cask는 공개 GitHub 릴리스의 DMG를 다운로드하고 SHA-256을 검증합니다. Apple Silicon·Intel에 맞는 파일을 자동 선택합니다. Windows x64 EXE는 [베타 릴리스](https://github.com/djfksjd/kkachi-releases/releases/tag/v0.1.0-beta.1)에서 받을 수 있습니다.

앱 내부 자동 업데이트, KKACHI 자체 관리형 AI와 API 키(BYOK) 방식은 이 베타에서 제공하지 않습니다. Claude·Codex(ChatGPT)·Gemini 구독 계정 연결 경로는 별도로 지원하며 계정 연결과 권한이 필요합니다. HWPX 외부 제출용 검증도 미완료입니다. 기능 제한과 첫 실행 방법은 [설치 안내](https://github.com/djfksjd/kkachi-releases/blob/main/docs/INSTALLATION.md)를 확인하세요.

사용자 문서와 작업공간 데이터를 자동 삭제하지 않으며 macOS 보안 기능을 해제하거나 격리 속성을 제거하지 않습니다.
